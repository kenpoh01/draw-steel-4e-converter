# draw-steel-4e-converter

Dnd 4e pdf monster converter
After installing this module, you can choose a 4e product.  The module will scan through looking for monster stat blocks and attempt to convert them to a draw steel compatible monster for the metamorphic Draw Steel system.  
This module is heavily dependant on how good the OCR pass was on the PDF and many errors can occur based on it's quality.
The module tries to detect the names and kinds of abilities and convert them to a draw steel tiered damage roll.  These are based on the Draw Steel rules and math.



This module needs to be manually installed from the FoundryVTT module installation tab.

Use this url to manually download: https://raw.githubusercontent.com/kenpoh01/draw-steel-4e-converter/refs/heads/main/module.json
